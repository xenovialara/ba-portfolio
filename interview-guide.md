Retention Engagement Conversion Segmentation and differentiation

| Your idea                        | Stronger elicitation question                                                                                                                                 | Technique                             |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| Convert trackers into purchasers | **What prevents active free users from converting to paid plans? At what stage of the journey is conversion highest/lowest?**                                 | Data analysis + stakeholder interview |
| Gamification/streaks             | **Which behaviours correlate most strongly with 30/60/90-day retention? What motivates users to return after completing a habit?**                            | Analytics + user interview            |
| Testimonials                     | **What information or social proof do users seek before purchasing premium?**                                                                                 | User interview/survey                 |
| Family plans                     | **Do users currently track health goals with partners/family? What would make a shared plan valuable enough to purchase?**                                    | Interviews + survey                   |
| Competitor churn                 | **What are the primary reasons users abandon our product or switch to alternatives?**                                                                         | Exit survey + competitor analysis     |
| Negative habits                  | **Do users want to reduce behaviours as well as build new ones? How do they currently track reduction goals?**                                                | User interview                        |
| Cost                             | **What development, operational and maintenance costs would each proposed feature introduce?**                                                                | Feasibility analysis                  |
| Beta testing                     | **How are engagement features currently validated before full release? What metrics determine whether an experiment succeeds?**                               | Stakeholder interview                 |
| User journey                     | **Walk me through the intended journey from onboarding → first habit → repeat usage → premium conversion. Where are the expected engagement hooks?**          | Process walkthrough                   |
| Mascot                           | **Would a persistent character, identity or progress system increase emotional attachment and return frequency?**                                             | Prototype testing/A-B test            |
| Gamification                     | **Which mechanics—streaks, milestones, levels, rewards, challenges or social accountability—have the strongest relationship with daily/weekly active usage?** | Analytics + A/B testing               |
| Female health                    | **Are there underserved health-tracking needs among different user segments? Which segments demonstrate particularly high recurring tracking needs?**         | Segmentation + interviews             |



**Business requirements:**
Increase retention.
Reduce churn.
Increase free-to-paid conversion.

Users need motivation to return.
Users need visible progress.
Users want easier tracking.
Some users may want accountability/community.
Users may need both build-a-habit and break-a-habit tracking.
